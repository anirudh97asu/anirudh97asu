## 🚀 Featured Projects

### 🛸 Semantic Segmentation on Aerial Imagery
End-to-end semantic segmentation pipeline on the TU Graz Drone Dataset (24 classes, 6000×4000 imagery) using U-Net with ResNet34 backbone via `segmentation_models_pytorch`. Full deployment with FastAPI + Gradio + Docker Compose.

### 🤖 Robotic Maze Solver
Perception-driven robot navigation pipeline combining **Grounding DINO** (open-vocabulary detection), **SAM** (segmentation), **A\* Search** (path planning), and **ChArUco board calibration**. Deployed on a PyDobot arm for physical execution.

### 🧬 Generative AI Agent for Robot Control
Agentic system leveraging Vision-Language Models to interpret scene context and generate structured robot control commands — bridging the gap between high-level language reasoning and low-level actuation.

### 🧱 LLM from Scratch (DeepSeek-V3 Style)
Custom PyTorch implementation of a modern LLM incorporating **Multi-head Latent Attention (MLA)**, **Mixture of Experts (MoE)** with loss-free load balancing, **GQA**, **RMSNorm**, and **RoPE**. Trained on Kaggle T4 GPUs with loss converging from ~10.9 → ~3.7 over 10k steps.
